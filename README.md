A make.fun bounty entry: one original line roasting a gadget I use every day.

## Entry

> My wireless earbuds die at 18% — not 5%, not 1% — 18%, like they negotiated an early retirement and forgot to tell me.

## How it works

`main.ts` (Node 22) writes the roast line to `/output/entry.txt` and checks it against the bounty gate (UTF-8 text, 1–200 characters, one line, not only whitespace) with a byte-for-byte read-back verification.

```sh
node main.ts
```
